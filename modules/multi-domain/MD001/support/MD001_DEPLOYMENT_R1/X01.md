# X01 adapter disclosure inventory — required, unscored

Signed format is unchanged: event.version integer1; event.producer_id DOMAIN_A;
event.key_id public-key fingerprint; event.artifact_id UUID; event.event_id
LOCAL_SORT_V1; event.outcome SUCCESS (or test-mutated FAILURE). These six fields
are externally disclosed and required by the schema. Producer identity/key enable
trust selection; event/outcome drive local criteria; artifact ID identifies and
links the assertion without consumption or single-use meaning. Event/outcome
deliberately disclose event category and asserted completion, not full execution
logic. Canonical envelope also includes the signature, required for cryptographic
verification. No new artifact fields or authorization semantics were introduced.

Transport is plaintext. Actual request metadata from this adapter includes numeric
Host/port, POST /verify HTTP/1.1, Content-Length, Content-Type application/json,
X-MH-Destination PROVIDER_B, and http.client's Accept-Encoding identity. IP/TCP
addresses, timing, sizes, sequence/connection behavior and route choices are visible.
Return metadata is HTTP status, Content-Type, Content-Length, Connection close,
and decision JSON with accepted/reason/signature_checks/artifact_sha256, verifier
PID, random process_instance, UTC, plus detail on malformed inputs. The custom
handler adds no Server/Date header. Relay may replace Host/hop-by-hop framing.
Error responses can expose diagnostic messages; all actual responses must be
included in the physical X01 wire inventory, not assumed from this source list.

Ingress/verification evidence additionally saves raw headers, peer port/address,
mode, hashes and case timestamps, and exposes them to the operator. Sender retains
sort inputs/output locally. Private test key stays on Dell under controlled evidence
preservation; it is never part of the transmitted artifact or deployment archive.
Captures and diagnostic logs expand disclosure to the operator holding them.

This is a source-based inventory validated against local adapter behavior. Inspect
actual physical artifact bytes, headers/responses and Pi captures during preflight/
scoring to complete physical X01. No absolute confidentiality or exhaustive absence
of leaks is claimed. Timing, host compromise and unrelated traffic are outside the
artifact-field claim. Refer to the retained original X01 for baseline context.
