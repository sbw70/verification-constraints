# Preserved source evidence

MP003/ is an unchanged, self-contained copy of 111 selected published MP003 files: top-level documentation, configs, public registry/trust keys and the evidence tree, including earlier retained material. MP004 directly uses the scored association log and campaign source artifacts. The additional MP003 evidence supplies context, not new MP004 scores.

All files are covered by configs/MP004_SOURCE_MANIFEST.json relative to MP003/. The 67 checksums in MP003/evidence/scored/SHA256SUMS.txt have that scored directory as their base. Original MP003 documentation inside this pinned copy is preserved as published, including relative links to implementation directories outside the selected subset; it is contextual source documentation, not a claim that this copy is a full MP003 checkout. Full implementation context remains in the original repository's MP003 module.

The source tree is never a mutation target. Laboratory fixture modifications are in ../../fixtures/. Only public boundary keys are required for MP004 verification. Published MP003 laboratory private keys are not needed here.
