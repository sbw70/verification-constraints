# MP004 Retained Evidence

This directory preserves superseded MP004 preparation artifacts that remain relevant to the history of the test definition.

It is not a scored-results directory.

## Contents

### `contract_draft_0_1/`

This subdirectory contains the pre-freeze MP004 contract draft and its matching draft source inventory.

Those files capture the state of the test definition before the selected MP003 source was tied to a specific published repository revision.

The later locked contract and source manifest supersede them for scoring.

## Why this material is retained

MP004 uses a locked test definition. Earlier drafts are preserved rather than overwritten so the progression from working definition to scored definition remains inspectable.

The retained draft shows that the core MP004 objective and negative-test structure existed before the final source comparison and contract lock, while also preserving the limitations of that earlier state.

## What this directory means

Material under `retained/` is historical provenance.

It may explain how the final test definition was reached, but it is not evidence that a scored case passed or failed.

The authoritative test definition is under:

- `../../configs/`

The authoritative scored output is under:

- `../scored/`

## Limits

Nothing in this directory should be used as a substitute for the locked contract, locked manifests, verifier output, or scored evidence.

There was no separate scored MP004 campaign under the retained draft.
